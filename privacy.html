Privacy policy

Effective November 16, 2026

Jarvis is a private, single-user assistant. Its only user is its owner, who connects his own Google accounts.

What data Jarvis accesses

With the owner's permission, Jarvis reads Gmail messages and Google Calendar events, creates email drafts, and, only after the owner explicitly approves each action, sends emails or creates calendar events.

How the data is used

Data is used only to provide the assistant's features to the owner. It is not sold, shared with third parties for advertising, or used to build user profiles. Content may be processed by AI model providers solely to generate the owner's responses.

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

Credentials are stored in an access-controlled secret manager. Conversation data is stored in a private database accessible only to the owner's own services. Access to the application requires the owner's Google sign-in.

Deletion

The owner can revoke Jarvis's access at any time at myaccount.google.com/permissions and delete stored data.
